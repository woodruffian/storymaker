# storymaker
Tell me your story, in your own words and images

## GitHub Codespaces

Open the repository in a Codespace. The dev container installs the pinned pnpm version, installs dependencies, creates the SQLite database from the Drizzle migrations, and forwards port 3000.

Start the app with:

```bash
pnpm dev
```

The app will be available at `http://localhost:3000`.
